## 3. 生活动线

```
将"动线设计"这个概念从商业空间引入个人生活。
展示你如何优化日常行为路径，让生活更高效、更愉悦。
```

### 什么是生活动线？

> 动线 = 人在空间中完成一个任务的完整移动路径。
> 好的动线让人"自然地做对的事"，不需要额外心力。

### 动线设计案例

| 动线 | 优化前的问题 | 优化后的方案 | 效果 |
|------|-------------|-------------|------|
| 起床动线 | 闹钟→摸手机→刷半小时→匆忙洗漱 | 手机不进卧室，床头放 Kindle，窗帘自动开 | 睡眠质量提升，晨间更从容 |
| 工作动线 | 【待填】 | 【待填】 | |
| 健身动线 | 【待填】 | 【待填】 | |
| 厨房动线 | 【待填】 | 【待填】 | |

### 动线设计原则（你的方法论）

1. **最短路径原则**：高频动作的路径越短越好
2. **自然触发原则**：让环境本身提示行为，而非靠记忆
3. **摩擦最小化**：想多做的事降低启动成本，想少做的事增加启动成本
4. **愉悦奖励**：动线的终点设计一个正反馈——比如健身后有准备好的冷萃咖啡
