# 艺术家风格 · 设计规划

> 为 HaiRong Chen 个人网站制定的艺术家风格设计方案
> 布局模式：单页 + 折叠区 (Single Page + Accordion)

---

## 一、设计理念

### 核心理念：有机秩序

冰川的纯净、深海的沉稳、晴空的通透——以蓝色系构建一个既理性又富有呼吸感的个人空间。大面积的有机曲线（山峦、波浪、叶片轮廓）作为装饰元素，在极简排版中注入自然流动的生命力。

### 四个关键词

| 关键词 | 解释 |
|--------|------|
| **有机曲线** | 圆形光晕、波浪曲线、SVG 叶片轮廓，打破矩形盒子的僵硬感 |
| **极简排版** | 大标题 + 简洁文案，信息层级通过字号/粗细/颜色区分 |
| **分块清晰** | 每个折叠区独立成块，白色圆角卡片承载内容 |
| **蓝色呼吸** | 从冰川白到午夜蓝的渐变体系，冷静而不冰冷 |

## 二、色彩系统

### 主色调（蓝色系）

| Token | 色值 | 用途 |
|-------|------|------|
| `--glacier` | `#f4f7fb` | 页面底色，微蓝冰川白 |
| `--ice` | `#eaf1f8` | 卡片表面、分割线 |
| `--frost` | `#d2e2f3` | hover / 激活态表面 |
| `--cloud` | `#ffffff` | 卡片/区块纯白底 |
| `--sky` | `#5b9bd5` | 核心强调色，按钮/链接/标签 |
| `--sky-deep` | `#3b7fc4` | 深天蓝，hover 激活 |
| `--sky-dark` | `#2b5f9e` | 最深蓝色点缀 |
| `--sky-light` | `#a8d4f0` | 浅天蓝，柔和装饰 |
| `--sky-ghost` | `#dceaf7` | 极浅蓝，标签/图标背景 |

### 文字色

| Token | 色值 | 用途 |
|-------|------|------|
| `--midnight` | `#0f1b2d` | 主标题文字 |
| `--navy` | `#1a365d` | 重要文字、卡片标题 |
| `--slate` | `#4a5568` | 正文、描述文字 |
| `--slate-light` | `#718096` | 辅助文字 |
| `--slate-muted` | `#a0aec0` | 最弱文字 |

### 有机点缀色

| Token | 色值 | 角色 |
|-------|------|------|
| `--leaf-green` | `#88b8a0` | 植物叶片装饰色 |
| `--leaf-light` | `#c5dfd0` | 浅叶绿，光晕层 |

### 配色原则

- **蓝色是唯一强调色**：不引入第二强调色，保持冷静克制
- **白色为主**：云白卡片 + 冰川白底色，呼吸感强
- **层级靠明度**：midnight → navy → slate → slate-light，四档自然过渡
- **光晕用模糊圆形**：装饰用 `blur(80px)` 的大圆，而非渐变或图片

## 三、字体系统

| 用途 | 字体 | 说明 |
|------|------|------|
| 标题 | **Outfit** (geometric sans) | 现代几何无衬线，大标题极有冲击力 |
| 中文标题 | **Noto Sans SC** | 思源黑体，匹配 Outfit 的干净气质 |
| 正文 | **Noto Sans SC + system sans** | 中文用思源黑体，英文用系统字体 |

### 字号阶梯

| 层级 | 字号 (mobile / desktop) | 用途 |
|------|------------------------|------|
| H1 | 2.4rem → 5rem | 姓名主标题 |
| H2 | 1.25rem → 1.4rem | 折叠区标题 |
| H3 | 1.05rem | 项目卡片标题 |
| Body | 0.9375rem → 1rem | 正文 |
| Caption | 0.6875rem → 0.75rem | 标签/辅助 |

## 五、折叠区交互设计

### 行为规则

1. 默认全部关闭
2. 手风琴模式：始终只展开一个区域
3. 展开动画 500ms `ease-out`
4. 箭头指示器旋转 180° + 背景色变化
5. 展开时区块自动滚动到视野内

### 视觉设计

- 白色圆角卡片 + 极淡蓝色边框
- 展开时顶部出现 `sky→sky-light→sky` 三色渐变装饰条
- 折叠指示器：圆形底 + SVG 十字线，展开时旋转 180°
- hover 时边框加深、标题变蓝
- 内容区展开时 fadeIn + slideUp

## 六、有机曲线元素

### 三层模糊光晕（背景固定）

| 光晕 | 颜色 | 位置 | 大小 | 动画 |
|------|------|------|------|------|
| orb-1 | sky 蓝 | 右上角 | 380px | 12s 慢速浮动 |
| orb-2 | sky-light 浅蓝 | 左下角 | 260px | 15s（偏移） |
| orb-3 | leaf-light 叶绿 | 中部偏右 | 200px | 18s |

### Hero 波浪曲线

Hero 底部使用 SVG `<path>` 绘制柔和的山丘波浪，颜色为 `ice` 半透明。

### 姓名波浪下划线

"Chen" 下方使用 SVG data URI 嵌入波浪线，重复铺开，模拟手绘 squiggle 效果。

## 七、响应式行为

| 断点 | 变化 |
|------|------|
| < 480px | 项目网格 2→1 列；信息网格 2→1 列；字号缩小 |
| > 768px | 布局展开：字号放大、内边距增加 |

## 八、动画清单

| 动画 | 触发 | 效果 | 时长 | 缓动 |
|------|------|------|------|------|
| Hero 淡入 | 页面加载 | opacity + translateY | 1s | ease-out |
| 光晕浮动 | 持续 | translate + scale 循环 | 12-18s | ease-in-out |
| 折叠展开/收起 | 点击标题 | max-height 过渡 | 0.5s | ease-out |
| 内容淡入 | 折叠展开后 | opacity + translateY | 0.45s | ease-out |
| 指示器旋转 | 点击标题 | 180° 旋转 | 0.35s | cubic-bezier |
| 卡片 hover | 鼠标悬停 | translateY(-2px) + 阴影 + 光点出现 | 0.35s | ease |
| 按钮 hover | 鼠标悬停 | 颜色加深 + 阴影扩散 | 0.3s | ease |
