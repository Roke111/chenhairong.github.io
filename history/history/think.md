# 思考 · Think

> 定位：展示认知深度——对市场的判断力、决策的底层逻辑、对未来的预判。
> 核心原则：不晒持仓盈亏，晒思考过程和验证结果。

---

## 一句话定位

> 在数据中寻找规律，在规律中构建策略，在策略中管理风险。
> 这里的每一篇思考，都是认知的刻意练习。

## 1. 量化交易

```
展示你的量化交易哲学、策略框架和复盘思考。
重点不是策略本身多赚钱，而是决策逻辑是否经得起推敲。
```

### 我的交易哲学

| 原则 | 解释 |
|------|------|
| 概率思维 | 不追求单笔必胜，追求统计意义上的正期望值。盈利 = 胜率 × 盈亏比 × 交易频率，三者不可兼得 |
| 系统化执行 | 情绪是交易最大的敌人。EA 的价值不在于策略多聪明，而在于执行从不走样 |
| 风控第一 | 活下来比赚得多重要。三重熔断的设计哲学是：允许小亏，控制中亏，杜绝大亏 |
| 持续迭代 | 市场在变，策略也要变。但每次改动必须有回测数据支撑，不能凭感觉 |

### 策略框架：EURUSD M1 头皮策略

```
以下为策略设计文档的摘要版，完整逻辑已在"工作"Tab的项目中展示。
这里侧重分享设计思路和迭代历程。
```

| 维度 | 设计逻辑 | 我的思考 |
|------|----------|----------|
| 为什么选 M1 周期？ | 分钟级波动提供更多交易机会，适合自动化执行 | 【待填：你为什么选择分钟级而非日线？】 |
| 为什么用 EMA × 3？ | EMA(10)捕捉短期动量，EMA(30)确认中期方向，EMA(100)定义长期趋势背景 | 三层过滤降低假突破概率 |
| MACD 为什么是确认而非触发？ | MACD 滞后于价格，不适合做入场信号，更适合做趋势强度确认 | 指标各司其职：EMA 做方向，MACD 做动能，RSI 做极值 |
| 为什么设计三重熔断？ | 单次交易的偶然性太大，需要在不同时间维度上控制暴露 | 单笔止损 → 保护单次交易；日熔断 → 防止情绪化连亏；总熔断 → 保护账户生存 |

### 选股原则

| 原则 | 具体做法 |
|------|----------|
| 自上而下 | 先看行业趋势，再看板块热度，最后选个股 |
| 龙头优先 | 宁可错过跟风，不追杂毛。一个板块的龙头往往是确定性最高的选择 |
| 数据驱动 | 不靠"感觉这个要涨"，每次决策记录判断依据，事后验证 |
| 连板逻辑 | 涨停不是结果，是信号。重点分析：板块效应 → 封板时间 → 封单力度 → 次日溢价的概率 |

## 关于"投资"与"思考"的命名

> "思考"比"投资"更合适——前者让你在谈论量化、选股、趋势时保持"分析者"的定位，而非"荐股者"。
> 它暗示的是认知分享，而非投资建议。这既保护了你，也让内容更有吸引力。
